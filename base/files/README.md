# SMM app

This project was created with smm-create-app.

## Scripts

- `yarn dev` — start the local development server
- `yarn build` — build Cloudflare Worker output
- `yarn start` — run the built Worker locally with Wrangler
- `yarn deploy` — deploy to Cloudflare

Open [http://localhost:3000](http://localhost:3000) after `yarn dev`. Edit `app/page.tsx` to start building.
